Estructura Básica de una Ventana Tkinter

Toda aplicación Tkinter sigue tres pasos fundamentales:

import tkinter as tk # 1. Crear la ventana principal root = tk.Tk() # 2. Configurar la ventana root.title("Mi Primera Ventana") root.geometry("400x300") # ancho x alto en píxeles # 3. Iniciar el bucle de eventos root.mainloop()

Elemento clave: mainloop()

Mantiene la ventana abierta esperando eventos del usuario (clics, teclas, etc.). Sin él, la ventana se cerraría al instante.

Resultado

Una ventana funcional de 400×300 píxeles con título "Mi Primera Ventana"

Widgets Esenciales de Tkinter

1 • Label

Etiqueta de texto. Muestra texto estático o imágenes que el usuario no puede editar. Ideal para títulos, instrucciones y mostrar resultados.

Propiedades: text, font, fg, bg, width, height

2 • Button

Botón clickeable. Ejecuta acciones cuando el usuario hace clic. El parámetro command= vincula una función al evento.

Propiedades: text, font, fg, bg, command, state

3 • Entry

Campo de texto. Permite al usuario escribir una línea de texto. Métodos importantes: .get() y .insert()

Propiedades: width, font, fg, bg, show

Widget Label: Ejemplo de Código

# Label simple label1 = tk.Label(root, text="Nombre:") # Label con propiedades de estilo label2 = tk.Label(root, text="¡Bienvenido!", font=("Arial", 16, "bold"), fg="white", # color del texto bg="#38bdf8", # color de fondo width=20 # ancho en caracteres ) label1.pack(pady=5) label2.pack(pady=5)
Parámetros principales:
  • text – El texto a mostrar
  • font – Tupla (nombre, tamaño, estilo): ("Arial", 14, "bold")
  • fg – Color del texto (foreground)
  • bg – Color de fondo (background)
  • width / height – Dimensiones en caracteres/líneas

Widget Button: Botones Interactivos

# Botón simple button1 = tk.Button(root, text="Haz clic") # Botón estilizado con comando (callback) button2 = tk.Button(root, text="Saludar", font=("Arial", 12), bg="#38bdf8", fg="white", width=15, height=2, command=saludar # función callback ) button1.pack(pady=5) button2.pack(pady=5)
Parámetro clave: command=

Vincula una función callback que se ejecutará cuando hagas clic en el botón.

⚠️ Importante: Escribe command=saludar (SIN paréntesis). Si escribes command=saludar(), se ejecutará al crear el botón, no al hacer clic.

Widget Entry: Campo de Entrada de Texto

# Entry simple entry1 = tk.Entry(root) # Entry estilizado entry2 = tk.Entry(root, width=30, font=("Arial", 12), fg="#334155", bg="#f1f5f9" ) # LEER el texto que escribió el usuario texto = entry2.get() # INSERTAR texto programáticamente entry2.insert(0, "Escribe aquí...") # BORRAR todo el contenido entry2.delete(0, tk.END) entry1.pack(pady=5) entry2.pack(pady=5)
Métodos importantes:
  • .get() – Lee el texto que escribió el usuario
  • .insert(posición, texto) – Inserta texto en una posición
  • .delete(inicio, fin) – Borra texto (0 a tk.END para todo)
  • .config(state="disabled") – Deshabilita la entrada

Callbacks: Respondiendo a Eventos del Usuario

Callback = Función que se ejecuta automáticamente cuando ocurre un evento (clic, escritura, etc.)

# 1. Definir una función callback def saludar(): print("¡Hola! Se hizo clic en el botón") # 2. Vincularla a un botón con command= button = tk.Button(root, text="Saludo", command=saludar # sin paréntesis (importante!) ) button.pack() root.mainloop() # Cuando hagas clic se ejecuta saludar()
Flujo de ejecución:
  1. Usuario presiona el botón
  2. Tkinter detecta el evento de clic
  3. Se ejecuta automáticamente la función callback
  4. El programa continúa esperando más eventos

Callbacks con Parámetros usando Lambda

Problema: Los botones no permiten pasar argumentos directamente en command=

# ❌ ESTO NO FUNCIONA button = tk.Button(root, command=saludar("Juan")) # Se ejecutaría al crear el botón, no al hacer clic # ✅ SOLUCIÓN: usar lambda (función anónima) button = tk.Button(root, text="Saluda a Juan", command=lambda: saludar("Juan") ) # Función callback que recibe parámetro def saludar(nombre): print(f"¡Hola, {nombre}!") button.pack()
Sintaxis Lambda:

lambda [parámetros]: expresión

Lambda crea una función anónima de una línea que captura los argumentos.

Gestores de Geometría: pack() vs grid()

Los gestores determinan cómo se posicionan y organizan los widgets en la ventana.

pack()

Apila widgets verticalmente de forma automática. Sencillo para layouts simples.

label1.pack(pady=10) label2.pack(pady=10) button.pack(pady=10) # Resultado: vertical

✅ Ventajas: Simple, perfecto para principiantes

❌ Desventajas: Difícil para layouts complejos

grid()

Organiza widgets en una tabla de filas y columnas. Control preciso.

label.grid(row=0, column=0) entry.grid(row=0, column=1) button.grid(row=1, column=0, columnspan=2)

✅ Ventajas: Control total, perfecto para formularios

❌ Desventajas: Más código necesario

⚠️ Regla de Oro: Nunca mezcles pack() y grid() en la misma ventana. Elige uno y úsalo consistentemente.

Manejo de Errores: try/except

Evita que el programa se bloquee si algo falla inesperadamente.

try: # Código que INTENTA ejecutarse num = float(entrada.get()) resultado = 100 / num label.config(text=f"Resultado: {resultado}") except ValueError: # Si el usuario escribió texto no numérico label.config(text="❌ Error: ingresa un número válido") except ZeroDivisionError: # Si el usuario ingresó cero (división por 0) label.config(text="❌ Error: no puedes dividir entre 0")

try

Intenta ejecutar el código. Si algo falla, se interrumpe y va a except

except

Captura el error específico y ejecuta código alternativo

Entendiendo mainloop(): El Bucle Principal

🔄 ¿Qué hace mainloop()?

Es un bucle infinito que:

  1. Espera eventos (clics, teclas, etc.)
  2. Procesa lo que el usuario hace
  3. Actualiza la pantalla
  4. Vuelve al paso 1 (infinitamente)

Sin mainloop():

ventana = tk.Tk() ventana.title("Test") # ❌ Sin mainloop() # Ventana aparece y desaparece # al instante
⚠️ IMPORTANTE: mainloop() SIEMPRE va al final de tu código, después de crear todos los widgets

Callbacks: Funciones Que Se Ejecutan al Hacer Clic

¿Qué es un Callback?

Una función que se ejecuta cuando ocurre un evento (clic de botón)

Ejemplo:

def al_hacer_clic(): print("Botón presionado") boton.config(command=al_hacer_clic)

Flujo de ejecución:

1️⃣ Usuario presiona botón

2️⃣ Tkinter detecta evento

3️⃣ Se ejecuta la función callback

4️⃣ Continúa esperando eventos

⚠️ IMPORTANTE: En command=, escribe el nombre de la función SIN paréntesis: command=saludar (no command=saludar())

Entry = Campo donde el usuario escribe texto (contrario a Label que es solo lectura)

Gestores de Layout: pack() vs grid()

📦 pack()

Apila elementos verticalmente (uno debajo de otro)

# Los widgets se apilan etiqueta.pack() entrada.pack() boton.pack() # Resultado: vertical
  • ✅ Simple para layouts básicos
  • ✅ Perfecto para principiantes
  • ❌ Difícil para layouts complejos

🔲 grid()

Tabla de filas/columnas (máximo control)

# Posicionar en tabla etiqueta.grid(row=0, column=0) entrada.grid(row=0, column=1) boton.grid(row=1, column=0)
  • ✅ Perfecto para formularios
  • ✅ Control completo
  • ❌ Más código
⚠️ REGLA: Nunca mezcles pack() y grid() en la misma ventana, elige uno

grid(): Sistema de Tabla (Filas y Columnas)

¿Cómo Funciona grid()?

Imagina una tabla de Excel:

  • row = número de fila (0, 1, 2...)
  • column = número de columna (0, 1, 2...)
  • Empezamos desde (0, 0) arriba a la izquierda
(0,0) Label (0,1) Entry
(1,0) Button (1,1) Label
# Ejemplo: Formulario con grid() tk.Label(ventana, text="Nombre:").grid(row=0, column=0, sticky="w") nombre = tk.Entry(ventana).grid(row=0, column=1) tk.Label(ventana, text="Email:").grid(row=1, column=0, sticky="w") email = tk.Entry(ventana).grid(row=1, column=1) boton = tk.Button(ventana, text="Enviar").grid(row=2, column=0, columnspan=2)
sticky: Alineación ("n", "s", "e", "w" = norte, sur, este, oeste)

Repaso Python: Funciones (Cruciales para Callbacks)

¿Por qué? Los callbacks SON funciones. Debes entenderlas bien.

# 1. Función SIN parámetros def saludar(): print("Hola") saludar() # Ejecutar # 2. Función CON parámetros def sumar(a, b): resultado = a + b return resultado print(sumar(5, 3)) # 8 # 3. Función que retorna valor def cuadrado(n): return n * n x = cuadrado(4) # x = 16 # 4. Función con valor por defecto def saludar_persona(nombre="Usuario"): return f"Hola, {nombre}" print(saludar_persona()) # Hola, Usuario print(saludar_persona("Juan")) # Hola, Juan
En Tkinter: Los callbacks son funciones SIN parámetros que se ejecutan al hacer clic

import tkinter as tk ventana = tk.Tk() ventana.title("Calculadora Completa") ventana.geometry("500x400") ventana.config(bg="#f0f9ff") def calcular(operacion): try: num1 = float(entrada1.get()) num2 = float(entrada2.get()) if operacion == "+": res = num1 + num2 elif operacion == "-": res = num1 - num2 elif operacion == "*": res = num1 * num2 elif operacion == "/": res = num1 / num2 if num2 != 0 else "Error: División por 0" resultado.config(text=f"Resultado: {res}", fg="#10b981") except ValueError: resultado.config(text="❌ Error: números válidos", fg="#ef4444") # Widgets tk.Label(ventana, text="Número 1:", bg="#f0f9ff", font=("Arial", 12)).pack() entrada1 = tk.Entry(ventana, width=30) entrada1.pack(pady=5) tk.Label(ventana, text="Número 2:", bg="#f0f9ff", font=("Arial", 12)).pack() entrada2 = tk.Entry(ventana, width=30) entrada2.pack(pady=5) # Botones de operaciones frame = tk.Frame(ventana, bg="#f0f9ff") frame.pack(pady=15) tk.Button(frame, text="+", command=lambda: calcular("+"), bg="#0284c7", fg="white", width=5).pack(side="left", padx=5) tk.Button(frame, text="-", command=lambda: calcular("-"), bg="#0284c7", fg="white", width=5).pack(side="left", padx=5) tk.Button(frame, text="*", command=lambda: calcular("*"), bg="#0284c7", fg="white", width=5).pack(side="left", padx=5) tk.Button(frame, text="/", command=lambda: calcular("/"), bg="#0284c7", fg="white", width=5).pack(side="left", padx=5) resultado = tk.Label(ventana, text="Resultado: -", font=("Arial", 14, "bold"), bg="#f0f9ff") resultado.pack(pady=20) ventana.mainloop()
Concepto nuevo: lambda

Lambda: Funciones Anónimas (Avanzado)

¿Qué es Lambda?

Función pequeña sin nombre de una sola línea

Problema:

Los botones NO permiten pasar parámetros directamente:

# ❌ ESTO NO FUNCIONA tk.Button( ventana, command=calcular("+") )

✅ Solución: Lambda

# Lambda resuelve el problema tk.Button( ventana, command=lambda: calcular("+") ) # Es equivalente a: def temp(): calcular("+") tk.Button(ventana, command=temp)
Sintaxis Lambda: lambda parámetros: expresión
